Anonymizer Role

The Anonymizer receives encrypted ballots and stores them in the ballot box. Before accepting a ballot, it verifies with the Commissioner that the N₁ code has not been used — preventing double voting.

The Anonymizer only ever sees the encrypted vote — it cannot read the vote content. It also verifies the admin blind signature to ensure ballots are authentic.

Voter sends: (C, s, N₂)

C = vote^e_counter (mod N_counter)
s = unblinded admin signature

Checks: s^e_admin ≡ m (mod N_admin)
Checks: N₁ not already used
